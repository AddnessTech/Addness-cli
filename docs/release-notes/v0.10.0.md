# v0.10.0

## Changed

- `comment create/reply/update/delete/resolve/unresolve/react/reactions`、TUI のコメント操作、`link pr/progress`、`notification send` は、表現可能な通常ケースで Goal Issue v2 API を優先する。
- message ID だけを受け取る既存 `comment` コマンドは、v2 preview から goal/root issue を解決するため、追加の `--goal` / `--issue` 引数は不要。
- v2 mutation の `--json` 出力は Goal Issue の snake_case resource になる。legacy-only fallback の場合は従来の comment resource を返す。

## Added

- `addness issue delete <ISSUE_ID> --goal <GOAL_ID>`
- `addness issue delete-message <MESSAGE_ID> --goal <GOAL_ID> --issue <ISSUE_ID>`
- 残存 v1 route と移行不可理由の全件監査台帳。

## Compatibility

次の契約は同等 v2 がないため、v1 fallback を維持する。

- 4,000文字を超える comment create/update
- mention row を変更する update
- Goal Issue 外の legacy comment
- global comment list、comment get/context、attachment delete
