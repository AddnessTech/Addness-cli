# v0.11.0

Codex CLI 0.153.4 / Claude Code 2.1.266 との互換性を検証し、TUI の履歴・出力・設定反映を修正しました。

## Added

- Codex のモデル選択に `gpt-6-astra`、推論強度に `max` / `ultra` を追加。
- Claude の権限モードに `auto` / `manual` を追加。`auto` を `dontAsk` として渡していた不具合を修正。
- Codex の `/sessions` を `thread/list` に対応。ページング履歴と exec/app-server/subagent のセッションを取得し、`/rename` は `thread/name/set` を使用。
- モデルカタログ、ページング履歴・rename、Claude 常駐ハンドシェイクを検証する実バイナリプローブを追加。

## Fixed

- 子プロセス終了後も stdout/stderr の末尾まで読み取り、結果・使用量・エラーの取りこぼしと次ターンへの混入を防止。
- `/add-dir` の変更を常駐プロセスへ反映。Claude の `list` が実際の一覧を表示し、`clear` が正しく解除するよう修正。
- `link pr` やリンク成果物の表示名に `/`・`\`・NUL が含まれる場合の API 400 エラーを防止。表示名を正規化し、URL 自体は保持。
- リリースビルドで `Cargo.lock` を固定。
- `lru` を 0.18.2 へ更新し、RUSTSEC-2026-0253 のメモリ安全性問題を解消。
- 認証不要の実バイナリ互換性プローブを通常の PR CI にも追加。

## Compatibility

- 履歴 API が利用できない Codex では従来の JSONL/index 読み込みにフォールバック。
- 一覧未取得でセッションを番号指定した場合は、先に一覧を表示して選択を求める。
- Claude の追加フォルダー内 inline MCP は、上流でフォルダーの信頼確認が必要。Addness は案内を表示し、信頼設定を自動変更しない。
- Claude の背景セッション用 `attach` / `logs` / `stop` / `respawn` / `rm` は上流 CLI で利用する。Addness の `/stop` は現在の TUI ターンを中断する操作。

詳細: [互換性監査](../compatibility-2026-09-09.md)
