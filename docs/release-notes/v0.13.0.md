# v0.13.0

CLIを現行Addness APIに合わせ、廃止済みAPIを呼び出すコマンドを削除しました。

## Breaking changes

- 廃止された旧AIゴールチャット、ToDoチャット、AIスレッド、ゴール直結KPI APIのコマンドを削除。
- `goal decompose`、`execution generate`、組織コンテキストの取得・更新・履歴コマンドを削除。
- 移行先と機能差を [`CLI API移行表`](../cli-current-api-migrations.md) に記載。

## Fixed

- 成果物登録などでJSONではない403を受けたとき、OWNER/EDITOR権限の問題と誤案内せず、WAFまたはセキュリティルールによるブロックの可能性を案内。
- HTMLエラーページをCLIのエラー本文に出さず、運用調査に使える安全な応答ヘッダー（Request IDなど）がある場合だけ診断情報に追加。
- 廃止済みAPIをCLIの現行エンドポイント一覧・移行資料へ反映。
