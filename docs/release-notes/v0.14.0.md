# v0.14.0

`addness goal complete` を追加しました。完了が確認できたゴール群を、深い子から親へ順に完了できます。

```bash
addness goal complete <goal-id> --recursive --dry-run --json
addness goal complete <goal-id> --recursive --json
addness goal complete <goal-id> --recursive --exclude <feedback-goal-id> --json
```

- 全階層と子一覧の全ページを取得し、標準のツリー取得にある深さ2の制限を受けずに処理します。
- `--dry-run` は更新せずに対象を表示します。
- `--exclude` は指定した未完了の枝と、それを含む親の完了を保留します。複数指定できます。
- 途中で失敗した場合は停止し、完了済みIDと失敗したIDを返します。再実行すると残りを処理します。
- 実行時に親や組織の変更、新しい未完了の子を検出した場合は停止します。
- `--recursive` なしでは、指定したゴール1件だけが対象です。
- `goal tree` のヘルプ・README・`addness skills` に、標準のプレビューは深さ2までであることを明記しました。

新しい依存パッケージやバックエンドの変更はありません。
