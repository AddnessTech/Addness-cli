# v0.15.0

MCP の最新機能を CLI から利用できる `addness mcp` を追加し、既存コマンドを現行 API に合わせました。

```bash
addness mcp list --json
addness mcp schema list_forms --json
addness mcp call list_forms --args '{"limit":20}' --json
addness mcp call <tool-name> --args-file ./arguments.json --json
```

- 組織 MCP の公開301ツールを確認。ツール一覧・入力仕様をサーバーから取得するため、今後の追加にも追従します。個人・copilot・OpenAI・運営用の入口も、それぞれのキーの権限で利用できます。
- コメント・検索・ゴール共有を現行 v2 API へ移行。成果物・PRリンク・ファイルアップロード・TUIの成果物操作は新 Drive に対応しました。
- 廃止された Codex ジョブ、旧スキル、個人ドキュメント、共有ツリー、旧議事録、請求書、ゴール alias/duplicate/recurring 等のコマンドと関連コードを削除しました。
- API キーでは使えない Clerk 認証限定の操作を CLI から削除しました。
- Meeting Bot の作成引数・レスポンスを現行仕様に更新。録画停止は `meeting bot stop` を使います。旧 `list/delete` は削除しました。
- `comment list-all` は `--author` 必須になりました。旧成果物の順序付き移動・メンション更新は現行契約にないため削除しました。
- 書き込みをタイムアウト後に自動再送しないようにしました。MCP のツール失敗は構造化結果を保持して非ゼロ終了します。

削除コマンドの全一覧と移行先は [MCP/CLI 対応と API 移行](https://github.com/AddnessTech/Addness-cli/blob/v0.15.0/docs/mcp-cli-parity.md) を参照してください。

新しい依存パッケージやバックエンドの変更はありません。
